# Logos de marcas

El CRM busca los emblemas de las marcas en esta carpeta.

Los archivos actuales fueron cargados como SVG de marca desde Simple Icons, excepto Mercedes-Benz, que fue cargado desde Wikimedia Commons porque la ruta de Simple Icons no devolvio contenido.

El sistema usa estos nombres:

- `audi.svg`
- `bmw.svg`
- `chevrolet.svg`
- `citroen.svg`
- `fiat.svg`
- `ford.svg`
- `honda.svg`
- `hyundai.svg`
- `jeep.svg`
- `kia.svg`
- `mercedes-benz.svg`
- `nissan.svg`
- `peugeot.svg`
- `renault.svg`
- `toyota.svg`
- `volkswagen.svg`

Si una marca no tiene archivo todavia, el sistema no muestra ningun emblema.
Para reemplazar cualquier marca por el archivo oficial del press kit o media center de la automotriz, guardar el nuevo SVG con el mismo nombre.
